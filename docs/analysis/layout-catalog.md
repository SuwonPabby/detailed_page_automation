# layout-catalog — 레이아웃 패턴 카탈로그

> 상태: **M3 (Good 9제품 207블록 기준, 38패턴)** — M4에서 Bad anti-pattern 확장 예정.

블록의 **구성 골격** 카탈로그. 장면(scene)을 정한 뒤(디자이너 사고 2단계) 여기서 후보 패턴을 고른다.

**사용 규약:**
- 예시 노드 ID를 `get_screenshot(fileKey="jjgud5OkeXKA4weyP3FEND", nodeId=...)` 으로 **그 자리에서 띄워 확인**한다. 이미지는 저장소에 없다 — Figma가 원본이다.
- **인접 블록에 같은 패턴을 쓰지 않는다** (design-principles C항).
- 하나의 블록은 보통 **패턴 2~3개의 결합**이다 (예: `numbered-point + evidence-chart + stat-pills`).

## 결합 규칙 (6제품 관찰)

1. **usp 블록의 표준 골격**: 넘버 헤더 → 헤드라인+본문 → 시각 근거 1~2개 → (콜아웃 마무리). 근거 자리에는 compare-2up / evidence-chart / process-seq / radial-diagram / document-proof / calendar-strip 중 택1 — **연작 안에서 근거 패턴을 매번 바꾼다** (글로우샷 POINT 1~5 전부 상이). 이것이 C항(다양성)의 실제 메커니즘.
2. **차트·표는 흰(밝은) 카드에 격리**하고 배경 위에 직접 그리지 않는다.
3. **근거에는 출처 각주** — 식약처/논문/USDA/특허번호. 개인차 고지("인체적용시험 결과이며 개인차가 있을 수 있습니다")가 건기식 필수 문구로 반복된다.
4. **콜아웃은 블록당 1회.**
5. **풀블리드 컬러 위 콘텐츠는 흰 라운드 카드**에 담는다 (글로우샷 `1:394`, 클렌즈 카드 연작).
6. **컨셉은 배경 질감·모티프로 구현된다**: 밀밭명가 한지+캘리그래피+금박(한국적), 올리빗 보태니컬 일러스트+패브릭 질감(유럽풍), 꿀잠모드 밤하늘(저녁). 레이아웃 골격은 공유하되 표면 처리로 차별화.
7. **다크 블록은 신뢰/클라이맥스 용도**: 수상(밀밭), 특허·제조(꿀잠 POINT5), ZERO 선언(클렌즈), Gift(올리빗). 페이지당 2~4회로 절제.

## 실무 파일에서 발견된 함정 (M3 — 파싱/생성 시 주의)

- **mega-block**: 일진와이어 `1:82355`는 10,616px 페이지 전체가 한 블록 — 블록 분리가 안 된 작업 파일. 생성 시에는 반드시 장면 단위로 블록을 분리할 것.
- **파편화**: 구스밀은 장식 폴리곤·각주·사진이 개별 블록으로 존재(72개 중 서사 블록은 ~51개). `layout`에 `fragment`/`divider`로 표기됨 — 서사 분석 시 제외.
- **오배치 프레임**: 일진와이어 섹션 안에 올리빗 장식 파편(`1:34096` 등), 클렌즈 주스 섹션 안에 올리빗 대안 시안 프레임(19블록, variant A) — 섹션 소속을 맹신하지 말 것.
- **시리즈 공통 패턴**: 클렌즈(보라) `1:84524`와 퓨레나 `1:83901`의 영수증형 카드 연작이 동일 — 같은 브랜드 계열은 패턴을 재사용한다.

## Anti-patterns (Bad 5종 실측 — M4 완료)

각 항목은 QA 코멘트 원문 + 실물 노드 ID. 스크린샷으로 언제든 재확인 가능.

| Anti-pattern | 실물 근거 (노드 ID) | QA 원문 |
|---|---|---|
| **동일 골격 연속 반복** | 감자 `10:86219` — 원형사진→캡션→풀폭사진→문단을 3연속, 7,258px. 토마토 `1:85647` vs `1:85677` — 체크 3행+사진 골격 인접 중복. 간편블럭국 `1:85259` — 같은 그릇/구도 3연속 | "단조로운 레이아웃", "비슷한 레이아웃이 반복된다(섹션 8과 섹션 9)" |
| **구매후기 전문 나열** | 아기 이불 `1:86047` — 리뷰 4개를 제목+5~6줄 전문으로, 3,991px | "구매후기는 전문을 쓰기보다 더 작게 효율적으로" (모범 반례: 구스밀 `1:1939`, 상하키친 `1:84812` 말풍선 볼드) |
| **저대비 단일 톤** | 상하키친 전 블록 베이지 단일 톤 (`1:84812` `1:84818`) | "폰트와 배경색 대비가 낮아서 가독성이 낮음" |
| **작은 폰트·좁은 행간** | 감자 `10:86218` 본문 | "폰트 행간이 작고, 폰트 사이즈가 작다" |
| **이미지·텍스트 겹침** | 간편블럭국 수상 블록(4~6 CHECK 연작 중, 특정 미확정) | "이미지와 수상기록이 겹쳐서 눈에 들어오지 않음" |
| **연속 밝은 배경 6블록+** | 올리빗 실측 (Good이지만 지적됨) | "배경 대비가 적음" → [design-tokens.md §4](./design-tokens.md) |

**Bad 페이지의 공통 붕괴 방식**: 레이아웃 패턴의 부재가 아니라 **변주의 부재**다. Bad 페이지도 photo-caption, icon-checklist 같은 정상 패턴을 쓰지만, 같은 패턴을 연속 반복하고(C항 위반), 명도 리듬 없이(A항 위반), 작은 본문(B항 위반)으로 조합한다. → 생성 시 패턴 선택보다 **패턴 배열**이 품질을 가른다.
