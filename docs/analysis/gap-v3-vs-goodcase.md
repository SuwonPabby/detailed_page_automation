# gap-v3-vs-goodcase — 같은 기획, 디자이너 완성본과 v3의 정밀 비교

> 2026-08-09. 비교 대상: **v3**(`e4Nto2oOgqwbCcrI6Y4Btb` 페이지 47:2, 루트 47:3, 24블록, 검수 83/100)
> vs **good case** — 같은 기획으로 디자이너가 완성한 구스밀/바로끼니 페이지
> (사용자가 v3 페이지에 반입한 SECTION `51:85` = 코퍼스 `Full_design 1:1305`와 동일물, 72블록 상세 데이터는 `data/blocks.json`의 goosemeal).
> 방법: v3 전 블록 스크린샷 + 코퍼스 구스밀 전수 분석 데이터 + 장면별 1:1 대조.

| # | 격차 | 심각도 | v4에서 해소 가능? |
|---|---|---|---|
| 1 | **실사 이미지의 지배력** | 🔴 결정적 | 에셋/생성 provider 필요 (구조는 준비됨) |
| 2 | **인물(셀럽)의 반복 등장** | 🔴 결정적 | 에셋 필요 |
| 3 | **사회적 증거(리뷰 카드) 부재** | 🟠 큼 | ✅ 지금 가능 — 기획안에 후기 데이터 있으면 |
| 4 | **임팩트 타이포 스케일 (168 vs 120)** | 🟠 큼 | ✅ 지금 가능 |

v3가 **앞서는 지점**도 있다: FAQ 블록(good엔 없음), 수치 출처·비교기준 각주의 성실성, compliance 안전성("영양 폭탄" 같은 good의 표현은 오인 리스크가 있다), 결정론 검증 가능한 구조. **격차의 본질은 구조·카피가 아니라 ①에셋 ②표현의 대담함이다.**

## 1. 실사 이미지 — 페이지의 주인이 다르다

- good: 서사 블록 51개 중 **이미지 커버리지 ≥0.5가 18개(35%)**, 여기에 별도 사진 파편 블록 다수. 원물 플랫레이·단면 클로즈업·조리 실사·모델컷이 화면을 끌고 가고 **텍스트는 사진 위에 얹힌다**.
- v3: 실사 0. designed placeholder(브랜드 그라디언트)가 자리만 지킨다. 텍스트가 모든 일을 한다 → qa C-5 밀도 경고 7블록의 근원.
- **교훈**: 레퍼런스에서 "여백"으로 보였던 것의 상당수는 여백이 아니라 **사진의 숨 쉬는 영역**이었다. 에셋 도착 전까지 이 격차는 구조적으로 못 닫는다 (검수자 총평과 일치).

## 2. 인물 — 신뢰의 앵커가 6회 반복된다

good은 윤형빈 실물이 서론(원형 컷)→추천대상(양팔 포즈)→구매옵션(제시 포즈)→클로징(제품 들고)으로 **포즈를 바꿔가며 재등장**해 페이지 전체의 톤 앵커가 된다. v3는 인물 0 — "윤형빈과 함께 만든"이라는 카피(47:59)만 있고 얼굴이 없다. 카피가 주장하는 것을 이미지가 증명하지 못하는 상태.

## 3. 사회적 증거 — good의 두 번째 기둥이 v3엔 없다

- good: `1:1939` 리뷰 카드 4장 — 별점+마스킹 닉네임+날짜, **핵심 문구만 볼드**, 좌우 교차 + 제품 썸네일. 그 앞에 140px "수많은 리뷰가 증명하는" 헤더. 말미에 포토리뷰 3,000원 쿠폰 배너로 리뷰 수집까지 설계.
- v3: 04b 공감 말풍선(가상의 소비자 목소리)이 근사치일 뿐, **실존 후기 인용이 없다**. 리뷰이벤트 띠(47:599)는 있으나 리뷰 본체가 없어 순서가 뒤집혔다.
- v4 액션: 기획안/스토어에서 실제 후기 3~4개를 받아 `review-cards` 패턴(코퍼스 검증됨)으로 삽입. **대가성 표기 유지.**

## 4. 타이포 — 스케일 낙차의 대담함

| 지표 | good | v3 |
|---|---|---|
| 최대 폰트 | **168px** (서론 "속세맛 다이어트식") | 120px (훅) |
| 상위 스케일 | 168·140·130·124·120·110 | 120·96·78대 |
| 헤드라인 처리 | 옐로 하이라이트 박스 안에 그린 글자, 원 넘버 배지, 도넛 %배지 | 마커 하이라이트·인라인 색전환 (있음, 그러나 면적 소극적) |

good은 블록당 한 번씩 **글자가 그래픽이 되는 순간**을 만든다(2g, 33.85%, 168px 선언). v3의 위계비 2.94는 규정을 지키지만, good의 임팩트 구간(140~168)이 통째로 비어 있다. **v4: 훅·클라이맥스 2곳에 140~168px 선언 타이포 도입.**

## 5. 컬러 — 옐로를 '포인트'가 아니라 '면'으로 쓴다

- good: #F4C347 옐로가 하이라이트 박스·칼로리 숫자·**블록 전체 배경**(칼로리 비교 블록은 옐로 풀블리드)으로 면적을 갖고 등장. 딥그린-옐로-블랙-트러플골드의 4色이 각자 블록 단위 무대를 가진다.
- v3: 골드 #E9B949가 마커·숫자에만 쓰여 **면적 점유가 거의 0**. 다크 4개가 전부 같은 딥그린 계열이라 클라이맥스끼리의 구분이 약하다 (good의 트러플 블록은 블랙×골드로 완전히 다른 온도).
- v4 액션: ① 칼로리비교(47:399) 또는 토핑비교(47:261) 중 1개를 옐로 풀블리드로 전환, ② 트러플(47:199)은 이미 블랙골드 — 유지.

## 6. 블록 경계 — 절취선이 '종이의 물성'을 만든다

good은 색면이 바뀌는 경계 **11곳에 지그재그 폴리곤(종이 절취선)**을 넣어 페이지가 "이어 붙인 전단지"처럼 읽힌다. 이것이 코퍼스 구스밀의 시그니처 수공예 장치다. v3의 블록 경계는 전부 직선 색 전환 — 텍스처는 얹었지만 **경계의 물성**이 없다. v4: 색면 전환 3~4곳에 zigzag divider(VECTOR path로 생성 가능, API 불필요) 도입.

## 7. 정보 그래픽 — 같은 데이터, 다른 밀도

| 장면 | good | v3 |
|---|---|---|
| 영양/재료 | 주먹밥 실사 중심 **궤도형 라벨 17개**+리더선 | 배지 13개 나열 + 빈 원 placeholder (47:335) |
| 함량 비교 | 도넛 배지 — **원 면적이 수치에 비례**(33.85% vs 18%) + 단면 실사 | 동일 기법 채택됨(47:226) ✓ — 실사만 없음 |
| 식감 공정 | 오븐 3단 디스크에 **불꽃 텍스처 실사** | 원 3개 + 라벨 (47:303) — 구조 동일, 표면 부재 |
| 특허 | **특허증 실물 스캔** 이미지 | 텍스트 각주로만 (특허 제10-2550241호) |

구조는 이미 상당히 이식돼 있고(도넛 비례·3단 공정), 부족한 것은 **각 그래픽의 표면(실사·질감)과 라벨 밀도**다.

## 8. v3가 앞서는 것 (지킬 것)

1. **FAQ 블록** — good엔 없다. 코퍼스 전반(9종 중 6종)의 표준이며 유지 가치 있음.
2. **각주 체계** — 수치마다 비교대상·시점·출처가 붙는다. good의 "영양 폭탄", "HACCP 인증 시설에서 제조하여" 배치 방식은 현행 compliance 기준으론 리스크 지점.
3. **결정론 검증 가능성** — SOLID 베이스 유지 구조라 qa_check가 계속 작동한다.
