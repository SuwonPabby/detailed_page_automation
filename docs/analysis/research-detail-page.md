# 리서치 — 한국 이커머스 상세페이지 디자인 (2024–2026, 식품 중심)

수집일 2026-08-15. 한국어 실무 소스 중심(브런치·고구마팜·아이보스·와디즈·1분상세·zedy·converta·
젠시스튜디오·PUBLY·플랫폼 규격·식약처). 반영처: SKILL §4(표면 가이드) · scene-taxonomy ·
craft-axioms §4(리듬) · detail-page-reviewer.
전환율 수치(92%·270%·+80%·15–20%)는 실무 블로그 2차 인용 — **방향성 근거로만** 사용.

## 1. 구성 문법 — 핵심 발견

- **3막 구조 표준**: 후킹(3초) → 설득(문제→해결→근거→장면) → 신뢰/망설임 제거. "길이보다 흐름"
- **사회적 증거는 상단이다**: 브런치 9단계 구조는 판매 증거·인증을 1~3단(훅 직후)에 배치.
  하단 단일 리뷰 블록은 낡은 패턴. 첫 노출 후기가 가장 영향력 큼 + 중간 반복 배치
- **CTA 3회**: 첫 화면 + **스크롤 뎁스 40–60% 구간(전환율 +15–20%)** + 말미(+모바일 고정).
  최종 CTA 직전에 긴급성(할인·한정·당일출고) 서브블록
- **중반 이탈 급증** → usp 연속 구간을 영상·후기 하이라이트·제조 비하인드로 절단 (리듬 자극)
- **블록당 1메시지, 핵심 강점 3개 압축** — 과다 나열은 '낡음' 신호

## 2. 표면(surface) 운용 — surface system의 외부 근거

⚠️ "표면 전환 규칙"을 명시한 단일 문헌은 없음 — 아래는 컷 분류 관행 + 색·여백 규칙 + 다크
팔레트 가이드의 **합성**이다.

- **컷 분류 = 표면 분류**: 누끼컷(단색 받침·스펙용) / 연출컷(풀블리드 사진·훅/사용장면) /
  원재료숏(신뢰). 실무 배합 기준치: **연출 3–4 : GIF 2–3 : 누끼 1** — 잘 만든 페이지는
  **사진 표면 다수, 단색 소수**. **누끼 단독 남발 = 저가 인상**
- **여백·배경 전환 = 주제 전환 신호** (zedy 명시 규칙): 작은 여백=정보 묶음, 큰 여백=주제 전환.
  → **표면 전환은 감정 비트 경계에서만** — surface system의 핵심 근거
- **다크 표면 스펙**: 순수 #000 금지(니어블랙), 다크 위 액센트는 웜 메탈릭(골드·코퍼),
  다크에서 폰트 웨이트 +1
- **질감 트렌드**: 2025–26 '물성매력' — 부드러운/유기적 촉각 질감 선호. 절차적 텍스처 방향 검증

## 3. 식품 카테고리 제약

- **식욕 색채심리**: 촉진 = 빨강·주황·노랑·핑크(웜), 억제 = **파랑·보라·초록·검정**.
  → L 표면은 웜 크림 계열이 식품 기본값. 그린은 "신선/유기농" 기호로 제한적.
  **D(다크) 표면은 프리미엄·인증·기술 비트 전용 — 시즐(식욕) 비트에 다크 금지**
- **시즐 컷 문법**: 풀샷/미디엄/클로즈업(질감)/원재료숏 4종. 45°가 "식탁 시선" 범용 최강.
  웜톤 3,000–4,000K 조명. 클라이맥스 = 최대 시즐 클로즈업
- **신뢰 스택**: HACCP·원산지·성분 — 마크만 두지 말고 문장으로 주장. 인증은 제품 직접 관련만.
  신선식품은 배송·콜드체인·검수가 신뢰 블록의 일부(fulfillment-trust)
- 비교 장면은 식품에서 지뢰밭 — 자사 구/신 비교·조리법 비교로 우회 (기존 compliance와 합치)

  슬라이스 + GIF 제거**가 파이프라인 요건 (백로그 후보)
- 이미지 속 글자는 네이버 검색이 못 읽음 — 검색은 텍스트 정보가, 전환은 이미지가 담당.
  이미지 아래 텍스트 요약 병기 권장
- 모바일 가독: 행간 1.4–1.6, 한 줄 30–40자

## 5. 신선 vs 낡음 (2025–26)

**신선**: 미니멀+대형 여백 / 숏폼 문법(블록당 1메시지·상단 5–10초 무음 세로영상) / GIF·영상
필수화 / 물성·촉각 질감 / 사용 시나리오 스토리텔링 / before-after 훅
**낡음**: 정보 꽉 채운 밀도 / 정적 이미지 나열만 / 과다 강점 나열 / 별점만 있는 후기 /
화려한 장식 배경 / 새벽감성형 톤(식품·건기식 비추천 — 와디즈 유형론: 식품은 선생님형·B급형)
