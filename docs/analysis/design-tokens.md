> 상태: **M3 완료** — Good 9제품 207블록의 REST 구조 데이터 + 스크린샷 판독 기준. 2026-08-08.
> 데이터 원천: `data/blocks.json` (재계산 스크립트: `scripts/extract_blocks.py --stats`)

## 1. 타이포그래피 스케일 (860px 폭 기준)

Good 9종의 텍스트 노드 1,609개 실측:

| 역할 | 크기 범위 | 근거 |
|---|---|---|
| 최대 임팩트 타이포 (ZERO, 핵심 선언) | 120~196px | 퓨레나 ZERO 196, 구스밀 서론 168, 밀밭 130 |
| **블록 헤드라인** | **70~100px (중앙값 88)** | 블록 max_font 142개 분포 p25=70 / med=88 / p75=100 |
| 서브 헤드/강조 카피 | 44~64px | |
| **본문** | **25~32px (전체 med=32)** | 전체 분포 p25=25 / med=32 |
| 각주/출처/고지 | 12~28px | 연출 고지 24~28, 정보고시 12 |

**design-principles B항("폰트 큼, 최소 64") 정밀화**: 64px 규칙은 **블록 헤드라인**에 적용된다(실측 80%가 64px 이상). 본문은 25~32px, 각주는 12px까지 내려간다. 모든 텍스트를 64px 이상으로 만들라는 뜻이 아니다 — **위계의 낙차**(헤드라인 88 vs 본문 32 ≈ 2.75:1)가 핵심이다.

## 3. 팔레트 — "지배 hue 1개 + 포인트 1개 + 중성 배경"

| 제품 | 지배 hue | 포인트 | 중성 배경 | 컨셉 |
|---|---|---|---|---|
| 글로우샷 | 오렌지레드 `#FF4010` | — | `#F9F8F8` `#FCF5EA` | 활기찬 |
| 꿀잠모드 | 딥네이비 `#040A19` | 옐로(달) | `#F7F8F9` | 신뢰/저녁 |
| 구스밀 | 딥그린 `#005027` | 옐로 `#F4C347` | 종이 텍스처 | 비건/친근 |
| 올리빗 | 올리브그린 `#586235` | — | 크림 `#F5F5EB` | 유럽풍 |
| 퓨레나 | 그린 `#276044` | — | 크림 `#EFEAE4` | 클렌즈 |
| 밀밭명가 | 브라운/레드(이미지) | 금박 | 한지 화이트 | 한국 전통 |
| 클렌즈 | 보라(래스터) | 옐로 | 연보라 | 통통튀는 |
| 파일변환 | 블랙 `#0E0E0E` | 오렌지 `#FF6C00` | `#F5F5F5` | 모듈/속도 |

**D항 검증 완료**: 9종 전부 지배 hue 1개 구조. 색이 3계열로 번진 사례 없음(구스밀이 그린+옐로 2계열로 가장 많고, 원문에서 "색상이 다양함" 지적을 받은 것과 일치). 중성 배경은 순백이 아니라 **미세하게 물든 오프화이트**(#F9F8F8, #F5F5EB, #EFEAE4)가 표준.

## 4. 배경 명도 시퀀스 (A항 정량화)

블록 배경을 L(밝음)/M(중간)/D(어둠)로 분류한 실측 시퀀스 (`bg_override` 반영):

```
글로우샷:  D+L L M L→M L L L L M D L M M→L L     (D/M 6회 — 리듬 있음)
꿀잠모드:  D D D D D D L L L L L D L L L L L D L L L L L  (오프닝 다크런 후 간헐 D)
밀밭명가:  L D D D L L+D L L L+D L L L L L L L L+D  (신뢰 구간만 D)
클렌즈:    M D+L L M L L D L M+D L D+L L L L
파일변환:  D L L D M L
올리빗:    L L D L L L D+L L L L L L L D+L L L L D L L L  (D 희소)
퓨레나:    L D+L L L L L D L L L L L
```

관찰:
1. **"어둡고-밝고" 교차는 엄격한 교대가 아니라 리듬이다.** 밝은 블록 2~5개 사이에 다크 블록이 악센트로 들어간다. 페이지당 다크 블록 2~6개.
2. **다크 블록의 용도는 정해져 있다**: 오프닝 훅(꿀잠·파일변환), 신뢰/수상(밀밭), 클라이맥스 선언(ZERO), 프리미엄 연출(구스밀 트러플), 클로징(올리빗 Gift).
3. **검증 사례**: D가 가장 희소한 올리빗이 정확히 "배경 대비가 적음"을 지적받은 제품이다. → Level 2 QA 판정 함수: 연속 L 블록 6개 이상이면 경고.
4. 복합 블록(D+L)은 블록 내부에서 명도 전환을 해결한다 — 특히 긴 블록.

## 5. 블록 리듬

| 지표 | 실측 |
|---|---|
| 페이지당 서사 블록 수 (파편 제외) | 6~23 (중앙값 14) |
| 블록 높이 | 중앙값 1,100~2,700px, 전환 스트립 150~900px, 최장 5,600px(밀밭 brand-story) |
| usp 연작 수 | 제품당 3~6개 (중앙값 4) |
| 페이지 총 길이 | 10,800~37,400px |

긴 usp 연작(4개 이상)에는 사이에 transition(스트립 또는 무텍스트 사진)을 끼워 호흡을 만든다.

## 6. 서사 전이 통계 (제품당 1표, 구스밀 순서 신뢰불가·일진 메가블록 제외 7종 기준)

- **오프닝**: hook 6/7 (예외: 올리빗 brand-story 목차). hook 직후는 problem 또는 usp.
- **본문 중심**: usp 연작 (넘버링 3~6개). 연작 중간에 transition/tip 삽입.
- **클로징 표준형**: `target-audience → usage-guide → faq → notice` 조합에서 선택. 실측 종료 블록: notice(식품·건기식 5종) / faq(서비스 2종) / target-audience(꿀잠) / brand-story(밀밭 — 정보고시 뒤 감성 여운).
- **notice(정보고시/영양정보)는 식품·건기식의 필수 블록** — 서비스(파일변환)·공산품에는 없거나 교환/반품 안내로 대체(일진).

## 7. 생성 시 적용 규칙 (요약)

1. 헤드라인 70~100px / 본문 25~32px / 각주 24~28px, 위계 낙차 ≥ 2.5:1
2. 팔레트 = 지배 hue 1 + 포인트 0~1 + 오프화이트 중성 배경
3. 다크 블록 2~6개를 훅/신뢰/클라이맥스/클로징에 배치, 연속 L 6개 금지
4. usp 3~6개 넘버링 연작 + 사이 transition
5. 클로징은 제품 유형에 맞게: 식품이면 notice로, 서비스면 faq로
6. 폰트는 Pretendard 우선(검증 후), 실패 시 Noto Sans KR — 위계 유지가 우선
