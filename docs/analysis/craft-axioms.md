# craft-axioms — "사람이 만든 것처럼 보이는" 상세페이지의 공리계

> 근거: `Full_design` Good 9종 / Bad 5종의 **실제 렌더 이미지 판독** (2026-08-09).
> 각 공리는 **렌더된 이미지만 보고 판정 가능**해야 한다. "위계를 좋게" 같은 문장은 공리가 아니다.
> 판정 주체: `detail-page-reviewer` 에이전트. 규칙 위반은 노드 ID로 지적된다.

**이 문서의 존재 이유**: 구조(장면·레이아웃 패턴)만 맞으면 페이지는 **와이어프레임**이 된다.
scene-taxonomy와 layout-catalog는 *무엇을 어디에* 놓을지를 정하고, 이 문서는 *그것이 어떻게 보이는지*를 정한다.
2026-08-09 첫 baseline 산출물이 구조 100% 준수에도 "AI가 만든 티"를 낸 원인이 전부 이 층위였다.

---

## 0. 실격 공리 (하나라도 걸리면 자동 FAIL)

레퍼런스 Good 9종 전체에서 **단 한 번도 나타나지 않은** 것들이다. 나타나면 그 자체로 아마추어 신호다.

| # | 실격 사유 | 이미지에서 검출하는 법 | 처방 |
|---|---|---|---|
| **F1** | **콘텐츠 폭이 한 번도 안 바뀜** | 전 블록의 좌우 여백이 동일(예: 전부 60px) → 풀블리드 0개 | 폭 3종(860/740/560~660)을 번갈아 (§1.2) |
| **F2** | **모든 카드가 같은 라운드값** | 12·16·18px 라운드가 페이지 전체에 균일 적용 | 사진은 각지게(0) 또는 원형, 카드만 라운드 (§3.4) |
| **F3** | **사진 자리가 회색 점선 박스** | 대시 스트로크 + 회색 채움 + 가운데 라벨 | 실물 없으면 §5의 designed placeholder |
| **F4** | **텍스트와 이미지가 절대 겹치지 않음** | 모든 텍스트가 이미지 bounding box 밖 | 최소 2블록에서 텍스트를 사진 위에/걸치게 (§1.3) |
| **F5** | **강조가 굵기 하나뿐** | 페이지 전체에 색상 강조·마커·말풍선 0개 | §2.2 강조 3종을 블록마다 최소 1개 |
| **F6** | **이모지를 아이콘으로 사용** | 🚚 📷 ✅ ❌ 🌶 등이 UI 요소 자리에 | 도형으로 그리거나 텍스트로 대체 |
| **F7** | **모든 블록의 상하 여백이 동일** | padding 편차 < 15% | 클라이맥스 블록은 여백 1.5~2배 (§4.2) |
| **F8** | **한 블록에 장식 레이어 0개** | 배경 위에 텍스트·박스만 존재 | 모티프·구분선·질감 중 1개 이상 (§3.3) |
| **F9** | **카드 안에 카드** (nested card) | 라운드+채움 컨테이너가 2겹 이상 중첩 | 안쪽 카드를 없애고 여백·구분선·타이포로 계층을 만든다 |
| **F10** | **중성 배경이 순수 무채색** | 스포이드 R=G=B (`#FFFFFF` `#F5F5F5`) | 지배 hue에서 **파생된** 오프화이트 (§3.5) |

> 첫 baseline(2026-08-09 v1)은 F2·F3·F4·F5·F6·F7·F8·F9·F10을 **전부** 위반했다. 구조는 옳았는데도.

### ⚠️ 메타 공리 — 디폴트를 다른 디폴트로 바꾸지 마라

2026년 기준으로 **"AI 티 벗어나는 법"으로 유행한 처방들이 이미 새로운 AI 디폴트다**: 크림/베이지 배경, 세리프 이탤릭 강조, 과도하게 조인 자간, 오로라 메시 그라디언트, 글래스모피즘, 그라디언트 텍스트.
따라서 **모든 선택은 이 제품의 컨셉·사실에서 파생되어야 한다.** "크림색이 고급스러우니까"는 근거가 아니다. "지배 hue가 딥그린이므로 중성색을 그린 쪽으로 물들인다"가 근거다. (design-principles E항 "컨셉과 그래픽의 일치"가 정확히 이것)

### ⚠️ 반증된 가설 — 중앙정렬은 실격이 아니다

영문 웹에서는 `centered_hero`가 AI 신호지만, **860px 세로형 상세페이지에서 중앙정렬은 정상 관습**이다. 레퍼런스 Good 9종의 오프닝 다수가 중앙정렬 `hero-question`이다.
좁은 캔버스에서는 좌/우 정렬의 표현력 자체가 낮다. → 판정해야 할 것은 정렬 방향이 아니라 **콘텐츠 폭이 변하는가(F1)** 와 **정렬 축이 한 번이라도 바뀌는가**다.

## 1. 구성 공리 (composition)

**1.1 — 블록은 "빈 배경 + 가운데 쌓기"가 아니라 하나의 그림이다.**
레퍼런스 Good 블록의 대다수는 사진이 블록 면적의 40% 이상을 차지하고, 텍스트는 그 사진과 **물리적으로 관계 맺는다**(위에 얹히거나, 붙거나, 선으로 연결).
판정: 블록 면적 대비 이미지 면적 < 25%인 블록이 연속 3개 이상이면 FAIL.

**1.2 — 최소 세 가지 폭 체계를 쓴다.**
| 폭 | 용도 | 레퍼런스 |
|---|---|---|
| **풀블리드 860** | 사진, 컬러 패널, 배너 | 옵션 카드 `1:1905` — 사진이 좌우 여백 0 |
| 본문 740 | 표·리스트·카피 | 대부분 |
| 좁은 600~660 | 각주, 부제, 호흡 | |
한 페이지에 풀블리드가 0개면 FAIL. 모든 블록이 같은 안쪽 여백(60px)이면 FAIL.

**1.3 — 겹침(overlap)이 최소 2회 등장한다.**
레퍼런스 실측: 리뷰 카드 `1:1939`의 원형 썸네일이 **카드 경계를 뚫고** 좌측으로 나온다. POINT3 `1:1533`의 제품 사진은 우측 화면 밖으로 흘러 잘린다.
겹침은 "레이어를 의도적으로 쌓았다"는 가장 저렴하고 확실한 사람의 흔적이다.

**1.4 — 좌우 교차 배치(zigzag)를 리스트에 적용한다.**
리뷰 4개를 같은 방향으로 쌓지 않는다. 레퍼런스는 흰 카드(좌정렬) ↔ 다크 카드(우정렬)를 번갈아 놓는다.
판정: 동일 구조 아이템 3개 이상이 정렬·채움까지 전부 동일하면 감점.

**1.5 — 잘림(bleed)과 여백 비대칭을 허용한다.**
사진은 프레임 밖으로 나가도 된다. 오히려 안 나가면 "박스에 넣어둔" 느낌이 난다.

## 2. 타이포 공리

**2.1 — 한 문장 안에서 색이 바뀐다.**
레퍼런스 훅 `1:1347`: "속세맛 다이어트식"(다크브라운) / "윤형빈의 식물성 저당 주먹밥"(올리브그린) — 같은 문단, 다른 색.
옵션 `1:1905`: "식물성 저당 **불고기맛** 주먹밥" — 한 줄 안에서 핵심어만 옐로.
Figma 구현: `setRangeFills(start, end, paint)`. **이것이 F5를 푸는 1순위 도구다.**

**2.2 — 강조 도구는 3종이며, 블록마다 최소 1개.**
| 도구 | 구현 | 레퍼런스 |
|---|---|---|
| **마커 하이라이트** | 텍스트 뒤에 색 사각형(높이 = 글자 40%, 하단 정렬) | "건강까지" 금색 마커 `1:1347`, "밥보다 많은 갈비살" 올리브 마커 `1:1533` |
| **말풍선 태그** | 라운드 사각 + 꼬리 삼각형, 헤드라인에 **겹쳐서** | "2배" `1:1533`, "37%/18%" 퍼센트 태그 |
| **인라인 색 전환** | setRangeFills | §2.1 |

**2.3 — 본문은 부분 볼드로 스캔 가능하게 만든다.**
리뷰 `1:1939`: "맛있고 **단백질은 많은데 지방은 적어서** 영양도 아주 우수합니다" — 핵심구만 볼드.
긴 문단(3줄 이상)에 볼드 구간이 0개면 감점. 이것이 design-principles F항("키 포인트가 한눈에")의 실제 구현이다.

**2.4 — 줄바꿈은 자동이 아니라 구성이다.**
"건강까지 / 잡았다!"처럼 의미 단위로 끊고, 줄마다 길이를 다르게 해서 형태를 만든다.
판정: 헤드라인이 2줄 이상인데 줄 길이가 거의 같으면(편차 <10%) 자동 줄바꿈 의심.

**2.5 — 숫자는 단위와 크기를 분리한다.**
"245**kcal**" — 숫자는 크고 굵게, 단위는 작게. 한 덩어리로 같은 크기면 밋밋하다.

**2.6 — 디스플레이 폰트를 헤드라인에 쓴다.**
레퍼런스 훅은 본문 고딕이 아닌 **강한 콘덴스드 디스플레이 서체**. 우리 환경에서는 `Black Han Sans`(임팩트) / `Jua`·`Do Hyeon`(친근)가 대응. 전 페이지가 Noto Sans KR 하나면 감점.

## 3. 색·질감 공리

**3.1 — 배경은 순색 플랫이 기본값이 아니다.**
레퍼런스 훅은 **질감(페인트 스플래터)**, 옵션은 사진, 성분은 오프화이트+사진. 완전 평면 단색 블록이 전체의 60%를 넘으면 감점.
구현 가능한 대체재: 선형/방사형 **그라디언트**, 반투명 도형 레이어, 큰 원형 컬러 블롭.

**3.2 — 같은 hue를 3단계 이상 명도로 쓴다.**
성분 배지 `1:1385`: 연한 그린 / 중간 그린 / 진한 그린이 섞여 배치된다. 전부 같은 톤이면 표처럼 보인다.

**3.3 — 페이지를 관통하는 모티프가 있다.**
구스밀은 **얇은 금색 세로선**이 블록 사이마다 반복 등장한다(`1:1347` 하단, `1:1533` 하단). 밀밭명가는 한지 질감+금박.
모티프 = 블록들이 한 사람의 손에서 나왔다는 증거. 최소 1종을 3회 이상 반복.

**3.4 — 형태 어휘를 섞는다.**
원형(인물·성분 썸네일) / 각진 풀블리드(제품 사진) / 라운드 카드(정보) / 말풍선(강조). 전부 같은 라운드값이면 F2.
라운드는 **역할별 계층**을 갖는다: full-pill은 태그·배지에만, 카드는 12~18px, 풀블리드 이미지는 0.

**3.5 — 중성색은 지배 hue에서 파생시킨다. (F10)**
순수 회색은 "죽어 보인다". 레퍼런스 Good 9종의 중성 배경은 전부 **미세하게 물든 오프화이트**다: `#F9F8F8`(글로우샷 오렌지레드) `#F5F5EB`(올리빗 올리브) `#EFEAE4`(퓨레나 그린) `#F7F8F9`(꿀잠 네이비).
⚠️ 단, **임의의 크림/베이지는 2026년 AI 디폴트**다. 딥그린 브랜드면 그린 쪽으로 물든 오프화이트(`#F3F6F1`)를 쓰지, 무근거 베이지(`#F7F5EF`)를 쓰지 않는다.

**3.6 — 금지된 "고급스러움" 클리셰.**
오로라 메시 그라디언트 / 글래스모피즘 / 그라디언트 텍스트 / 컬러 글로우 / 퍼플-블루 그라디언트 CTA. 전부 AI 신호로 등록된 패턴이다.

## 4. 리듬 공리

**4.1 — 모든 블록이 같은 중요도를 갖지 않는다.**
페이지에는 **클라이맥스 블록 1~2개**가 있어야 한다: 가장 크고, 가장 어둡거나 가장 채도 높고, 여백이 가장 넓은 블록.
판정: 블록 높이의 표준편차가 평균의 25% 미만이면 "평평한 페이지" 감점.

**4.2 — 여백은 중요도의 함수다.**
클라이맥스 블록 상하 여백은 평균의 1.5~2배. 각주·배너는 0.3배.

**4.3 — 다크 블록은 2~6개, 용도가 정해져 있다.** (→ design-tokens §4)
훅 / 프리미엄 연출 / 신뢰·수상 / 클라이맥스 선언 / 클로징. 연속 L 6개 이상이면 경고.

**4.4 — 인접 블록은 같은 골격을 쓰지 않는다.** (→ layout-catalog, Bad 페이지의 유일한 공통 사인)
usp 연작은 근거 패턴을 매번 교체한다.

**4.5 — 호흡 블록을 넣는다.**
150~900px의 짧은 전환 스트립 또는 무텍스트 사진. 정보 블록 4개 이상 연속이면 사이에 필요.

## 5. 에셋 부재 시의 규약 (designed placeholder)

실물 사진이 없을 때 **회색 점선 박스는 금지(F3)**. 대신:

1. **최종 형태로 자리를 잡는다** — 원형이면 원형, 풀블리드면 좌우 여백 0, 잘릴 거면 잘리게.
2. **채움은 브랜드 팔레트의 저채도 그라디언트** (예: `#0B3A1E`→`#14532B`). 회색 금지.
3. 라벨은 **하단 구석에 작게**(18~20px, 40% 불투명) — 가운데 큰 "ASSET" 금지.
4. 프레임 이름은 `IMG_<장면>_<설명>` — 에셋 도착 시 스크립트로 일괄 치환 가능하게.
5. 사진 위에 얹힐 텍스트는 placeholder 위에 **미리 얹어 둔다**(F4 회피). 실물이 들어와도 레이아웃이 안 바뀐다.

## 6. 카피 공리

**6.1** 한 블록의 메시지는 **하나**다. 헤드라인이 두 가지 주장을 하면 쪼갠다.
**6.2** 숫자는 반드시 **비교 대상과 함께** 제시한다("245kcal" 단독 ✗ → "즉석밥 315kcal 대비" ✓).
**6.3** 규제 표현은 기획안 L열(방어/거절) 판정을 따른다. 판정문이 없는 신규 표현은 만들지 않는다.
**6.4** 각주(※)는 근거가 필요한 블록마다. 레퍼런스는 연출컷 고지를 **6회** 반복한다 — 성실함의 신호.
**6.5** 클리셰 금지: "완벽한", "최고의", "특별한", "믿을 수 있는" 등 검증 불가 형용사.
**6.6 치환 테스트** — 제품명을 가리고 읽었을 때 다른 제품에도 그대로 성립하는 문장이면 실패다. "우리 대표가 실제로 이렇게 말할까?"가 Yes가 될 때까지 다시 쓴다.

## 6.5 겹침의 가독성 계약 (F4를 지키되 실패하지 않는 법)

겹침이 없으면 밋밋하지만(F4), **잘못된 겹침은 실측된 Bad 판정**이다 — 간편블럭국 수상 블록 QA 원문: *"이미지와 수상기록이 겹쳐서 눈에 들어오지 않음"*.
따라서 텍스트를 이미지 위에 얹을 때는 **셋 중 하나를 반드시 동반한다**:

1. **스크림** — 이미지 하단/상단에 투명→불투명 그라디언트 오버레이
2. **솔리드 플레이트** — 텍스트를 카드/패널에 담아 이미지 위에 얹음
3. **의도적 저주파 영역** — 이미지 안에 비워둔 공간(하늘·여백 벽면)에만 텍스트 배치

판정법: 이미지를 **그레이스케일로 변환**했을 때 글자가 여전히 읽히면 통과. 차트·표는 예외 없이 **밝은 카드에 격리**하고 배경 위에 직접 그리지 않는다.
