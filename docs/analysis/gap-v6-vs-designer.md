# 격차 전수 분석 — 디자이너 완성본 vs v6 (2026-08-16)

대상: 같은 파일의 디자이너 구스밀(SECTION `51:85`, 48,936px·928노드·이미지 102장) vs
우리 v6(`88:2`, 21,611px·470노드·이미지 25장). 같은 제품 — **디자이너는 2.3배의 스크롤과
4배의 사진**을 쓴다. 전 블록 렌더 실견 + REST 실측. 총 34건.

원인 분류: ⓐ 규칙 부재 / ⓑ 규칙은 있으나 실행 얕음 / ⓒ 에셋·데이터 부족

## 핵심 결론

> **디자이너는 규칙을 더 잘 지키는 게 아니라, 어디에 물량을 쏟을지 먼저 정하고
> 규칙을 그 수단으로 쓴다.**

- 지배 요인은 **ⓑ 실행 얕음(17건)** — v3 백로그의 "지금 가능" 항목(임팩트 타이포·옐로 면·
  궤도 라벨)이 5라운드 검수를 **통과하면서도** 실행되지 않았다. 검수 루프는 하한(실격·감점
  회피)만 지키게 한다. **하한이 목표가 되는 구조적 문제.**
- ⓐ 12건의 다수는 블록 공리가 아니라 **페이지 단위 자원 배분**(클레임 서열→물량,
  물성 세계관, 그레이드 통일)의 공백.
- 순수 에셋 문제(ⓒ)는 7건뿐 — "재료가 없어서"가 아니다.

## ① 격차 리스트 (층위별 34건)

### 사진의 운용
- **G1 누끼 완전 부재** ⓐ+ⓒ — 디자이너는 컷아웃을 도형처럼(모델 누끼가 색면 경계에 걸침,
  단면 스택 우측 블리드, 3D 트럭). 우리는 25장 전부 직사각 씬 사진이 카드 안에.
  remove_background 도구는 있는데 "사진 형태 3종(씬/원형/누끼)" 규칙이 없다
- **G2 단면이 클레임을 증명** ⓑ — "밥보다 많은 갈비살"을 단면 실사 + **점선 리더선으로
  수치를 사진 지점에 앵커**. 우리는 통주먹밥 + 분리된 바 차트
- **G3 소품 스타일링 밀도** ⓒ — 통마늘·바질·채반·린넨·반쯤 잘린 그릇(잡지식 플랫레이) vs
  단일 피사체 + 흐린 배경
- **G4 클레임 중요도 ∝ 사진 투자** ⓐ — 디자이너 1순위 클레임(당류) 블록 6,183px·이미지
  11장·커버리지 82%. **우리 05_당류안내는 이미지 0장** — 배분 규칙이 플랜 단계에 없다
- **G5 경계 무시 블리드** ⓑ — 이탈 노드 32 vs 6 (우리는 ±10~120px의 소심한 블리드)
- **G6 인물 앵커 4회 대형 포즈 변주** ⓒ vs 130px 원형 1회 (T2 계약 모델 실사)
- **G7 이미지 0% 블록** ⓑ+ⓒ — 디자이너는 챕터 스트립조차 종이 질감 깔림. 우리는 5블록 텍스트-온리

### 타이포그래피
- **G8 임팩트 스케일 후퇴** ⓑ — 디자이너 110px+ **22회**(최대 168) vs 우리 최대 96px 1회.
  v3(120px)보다도 후퇴
- **G9 콘덴스드 부재** ⓑ — 디자이너 헤드라인 45회 전부 Cafe24 PRO Slim(장체 — 168px이
  가능한 이유). 우리 Black Han Sans는 96px에서 벽처럼 무겁다. 공리에 장체/평체 선택 기준 없음
- **G10 인라인 혼합 밀도 21% vs 9%** ⓑ
- **G11 숫자가 그래픽** ⓑ — 숫자가 막대 안에, "<"를 비교 연산자로, "2배" 말풍선 헤드라인 겹침,
  -90° 회전 COUPON. 우리 숫자는 전부 셀·배지 안
- **G12 소수점의 배신** ⓐ — 디자이너 본문 37%/18% + 라벨값 각주. 우리 37.81%를 헤드라인급
  위치에 — 정합은 얻고 그래픽 파워를 잃음. 반올림+각주 병기는 합법
- **G13 강조 어휘 8종+ vs 4종** ⓑ — 하한("3종 중 1개")이 목표가 됨

### 색·질감
- **G14 레드 축 부재** ⓐ — 디자이너는 그린-골드에 레드(#C41500…)·옐로·올리브 5축, 맛별 색
  코딩(불고기=다크레드/제육=레드오렌지). 우리 상위 18색 전부 그린+골드 1축
- **G15 옐로 면 운용 잔존** ⓑ — 디자이너 옐로 풀블리드 무대 2블록(6,183+2,177px) vs 우리 ~1%
- **G16 질감의 사실성** ⓒ+ⓑ — 디자이너 질감은 전부 사진(시멘트 -46.5°, 종이 부스러기,
  불꽃 실사, 꿀 매크로)
- **G17 모티프가 기계적** ⓑ — 디자이너 4종이 **변주**되며 반복 vs 우리 골드 바 1종이 같은
  좌표·크기로 스탬프. §3.3에 "변주" 요구 없음
- **G18 제품 파생 형태** ⓐ — 넘버 배지가 **주먹밥 삼각형** vs 우리 범용 원·필

### 구성·레이아웃
- **G19 인터락(요소가 서로 물림)** ⓑ — 썸네일이 컬럼 경계 위에, 사진이 카드 모서리 침범,
  특허증 위 플레이트. 우리 겹침은 스크림 캡션 1기법 반복
- **G20 회전 0** ⓑ — 디자이너 회전 노드 27(테이프 ±12°, 스티커 -20°) vs 우리 0
- **G21 비교표의 권력 구조** ⓐ — 타사 열 저채도 침강 + 자사 열 승격. 우리는 동격 카드
- **G22 각주가 지면을 점유** ⓐ — 디자이너 각주는 1줄 마이크로 타입을 사진 구석에.
  우리 07은 블록의 ~40%가 고지 패널

### 리듬·서사
- **G23 물리량 낙차** ⓐ — 높이 303~6,183px(σ/μ 0.70) vs 114~1,515px(0.42).
  **어떤 장면도 커지도록 허락받지 못했다.** 공리는 하한만 있고 클라이맥스 최소 물리량이 없다
- **G24 멀티 증거 스택** ⓐ — 한 클레임에 5중 증거 한 막(리뷰→168px 선언→차트→비교표→시즐)
  vs 우리 3요소 1,179px
- **G25 전환 어휘 5종 vs 1종** ⓑ — 종이 절취·책장 커브·챕터 스트립·색면·풀블리드 vs zigzag 복제 3회
- **G26 사회적 증거 0 잔존** ⓒ — 첫 1/3에 리뷰 실물 4장 vs 우리 0장 (실존 후기 미확보)
- **G27 오프닝 즉답성** ⓑ — 첫 화면에서 5특장점으로 서사 예고 vs 훅 다음 1,498px 지점

### 정보 디자인
- **G28 면적 비례의 드라마** ⓑ — 1000g 기둥 vs 소멸한 0g 기둥. 우리 바는 12px 필 — 비례는
  맞으나 드라마 없음
- **G29 궤도 라벨 다이어그램 미실행** ⓑ (v3 백로그 5번)
- **G30 물증 스캔 부재** ⓒ — 특허증 스캔·라벨 전면 게시 (T2 — 사람만 주입)
- **G31 큐레이션 층** ⓑ — 조리법에 "가장 맛있는/빠른/요리다운" 판단 라벨 층

### 디테일·마감
- **G32 일러스트·아이콘 계층 부재** ⓐ — 동판화풍 트러플 일러스트, 라인 아이콘, 3D 렌더,
  쿠폰 티켓. 우리는 0개 — F6(이모지 금지) 회피가 "아이콘 회피"가 됨. T1에 일러스트 클래스 미정의
- **G33 사진 톤 페이지 통일** ⓐ — 전 사진 웜 그레이딩 일치 vs 우리는 컷마다 온도 상이
- **G34 사진의 의미 정합** ⓒ+ⓑ — 우리 10_고기맛 클로즈업은 **패티 덩어리** — 디자이너가
  '타사(퍽퍽한 패티)'로 대비시킨 그림을 자사 증명으로 씀. asset-validator에 "클레임 일치" 공백

### 언어화 어려운 것
- **G35 물성 세계관** ⓐ — 디자이너는 "이어 붙인 스크랩북"이라는 **하나의 허구**를 끝까지 유지
  — 세계관이 장치들을 낳는다. 우리 zigzag는 장치 하나의 인용. 1단계에 "물성 컨셉 선언" 항목 부재
- **G36 카피의 체온** ⓑ — "꽉-찬 토핑!"·"넘사벽!" 선언·감탄·구어 혼합 vs 해요체 단일 톤
  (중앙값 수렴의 카피 버전)

## ⑤ 번역 가능성

- **즉시 규칙화**: 스케일 밴드 하한(130px+ 선언 2회/페이지), 클라이맥스 액트 규격(최장 블록 +
  증거 3종 적층), 누끼·리더선·앵커 빌더 기법, 회전 예산(3~5/페이지), 모티프 변주 요구,
  자사 열 승격 표, 각주 마이크로 스타일, 반올림+각주 표기, 맛별 색 축, 에셋 게이트 2종
  (클레임 일치·그레이드 스펙), 제품 파생 배지 형태
- **사람 선언 + 기계 수행**: 물성 세계관 1줄, 시즐 아트디렉션, 카피 체온 비율
- **사람만 (T2)**: 실존 리뷰, 특허증·라벨 스캔, 계약 모델 실사

## 다음 단계 함의

v7도 같은 자리에 수렴한다. 플랜 단계에 "클레임 서열 → 시각 자원 배분" 결정을 추가하는 것이
단일 최대 레버리지다.
