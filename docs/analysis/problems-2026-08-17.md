# 문제 정리 — 프레임워크가 기획서에서 발산하는 원인 (2026-08-17)

> v7 실행 중 사용자 지적("기획서를 하나도 안 읽고 기획을 멋대로 변경하고 있다")에 대한
> 원인 분석 결과. 처방 반영 전의 **문제 기록**이며, SPECIFICATION.md가 교정의 기준이다.

## 0. 실증 데이터 — 기획안 카피 잔존율 (동일 잣대 전수 대조)

기획안(goosemeal-v6.json) 장면 카피 40건을 디자이너 완성본(v3, `51:85`)과 우리 v7(`166:3`)의
실제 페이지 텍스트에 대조한 결과:

| | 원문 그대로 | 부분(핵심어) | 소실 |
|---|---|---|---|
| **디자이너 v3** | **21/40 (52%)** | 14/40 | 5/40 |
| **우리 v7** | **5/40 (12%)** | 25/40 | **10/40** |

v7에서 통째로 소실된 대표 항목:
- scene 25 **"계란 1개보다 높은 단백질"** — 페이지에 단백질 언급 자체가 없음 (aux에 단백 5g/6g 데이터까지 제공됐음)
- scene 31 **영양소 장면** — 시각화 없음 (나트륨 655/600mg 등 제공 수치 미사용)
- scene 30 "슈퍼곡물 3종+씨드 3종+뿌리채소 6종=12종" 분류 체계
- side_table **[S4] 저당 비교표** ("체외 배출" 등) — 미사용
- 배너 조건 **"매월 선착순 5명"** — 17_리뷰배너에 누락 (조건 은폐 = compliance 문제이기도 함)
- scene 23 "바로끼니의 기술력으로 씹는 맛 그대로 재현"

**디자이너는 기획대로 갔고 우리는 안 갔다.** 디자이너 v3는 원문 52%로 1라운드 83점 통과
— 기획 준수와 P1(AI 티 안 나기)은 충돌하지 않는다는 실증.

## 1. 근본 원인 — 한 문장

**디자이너의 재량은 조형(레이아웃·타이포·색·리듬)에 국한되고 내용(카피·순서·구성·수치)은
기획서 그대로인데, 프레임워크가 재량의 경계를 내용까지 확장했다.**
기획서가 '사양서'에서 '재작성용 원재료'로 강등됐다. 나머지 문제는 전부 이것을 못 막은
강제 장치의 구멍이다.

## 2. 골격 이탈 5건 (프레임워크 문서 자체에 심어진 것)

### V1. SKILL.md에 스펙에 없는 단계 추가 — '세계관 도출 + 카피 재작성 권한'
- 스펙 1단계는 font/color/surface 체계 수립뿐. 여기에 §4-0 스타일 탐색·세계관·서브팔레트와
  "프레임 카피 재작성(copy_decisions 기록만 하면 허용)"을 추가로 명문화함
- "속세맛은 죄가 없다", 판결요지 재편성, 특장점요약(scene 1~5) 해체가 전부 이 권한에서 나옴
- 디자이너는 이 권한을 행사한 적이 없음 (동일 기획, "건강까지 잡았다!" 원문에 마커만 추가)

### V2. 채점계가 이탈을 보상하도록 설계됨
- anti-AI 리서치 이관 시 reviewer 기준에 "중앙값 이탈·제품 특정적 세계관"을 가점으로 넣음
- 실제로 라운드 1 reviewer가 컨셉 이탈을 '잘한 것'으로 칭찬 — 루프를 돌수록 기획에서
  멀어지는 방향으로 수렴하는 인센티브 구조
- P1의 정의가 스펙("디자이너 완성본과 구분 불가")에서 "독창적 컨셉"으로 표류

### V3. P2(템플릿)가 플랜 스키마에서 증발
- plan blocks에 layout-catalog **template_id 필드도, 커스텀 사유 필드도 없음**
- transplant.py(템플릿 이식기)를 만들어 놓고 v7은 전량 즉석 커스텀 코드 조립 — 사유 기록 0건
- "템플릿 우선, 안 되면 사유 있는 커스텀"(R5)이 구조적으로 검사 불가능

### V4. 게이트가 명목 검사만 함
- traceability는 장면 **ID 귀속만** 검사 — "scene 25 → 블록 07" ✅로 통과하고,
  07에 해당 문구가 실재하는지는 검사하지 않음 (**명목 커버리지 ≠ 실질 커버리지**)
- side_tables·banners(조건 필드)·aux는 파싱만 되고 플랜 스키마에 소비 경로 자체가 없어
  파싱 후 증발

### V5. 4단계 즉흥 창작
- 스펙: "4단계는 조립만, 새로 창작하지 않는다"
- 실행: 검수 라운드마다 카피·각주·라벨·블록 구성을 그 자리에서 창작/수정.
  수정이 2단계(플랜)로 회귀하지 않음 — 관통 원칙 3 위반

## 3. 부속 문제

- **폰트(R6) 검증 부재**: taxonomy는 "세리프=디폴트, 산세리프=무드 조건부"인데 v7 주력 3종이
  전부 산세리프이고 선택 근거가 플랜에 없음. config/fonts.json roles ↔ 플랜 대조 게이트 부재
- **HITL 정보 비대칭**: 플랜 승인 시 copy_decisions 1줄로 뭉뚱그려져, 카피 40건 중 35건이
  재작성·소실될 계획이라는 규모 정보가 승인 시점에 드러나지 않았음
- **v7 검수 현황(미완)**: 라운드 2 red-team 완료(위반 6건 — 유틸리티 스트립 F8 3건, 08 최상급
  3건 잔존, 04b 별점 비마스킹, 04b 광고표시 슬롯 부재), reviewer 라운드 2 진행 중이었음.
  단, 위 근본 문제로 인해 **v7 실행 자체가 스펙 위반 상태** — 라운드를 더 도는 것보다
  프레임워크 교정이 선행돼야 함

## 4. 교정 방향 (미실행 — 지시 대기)

1. **재량 재국한**: SKILL.md에서 카피 재작성·장면 재편성 권한 삭제. 내용은 기획서 소유,
   재량은 조형만 (R1). 표현 변경이 필요하면 HITL에 개별 항목 단위로 노출해 승인받는다
2. **게이트 신설 4종**:
   - 카피 잔존 게이트 (장면 문구가 귀속 블록에 실재하는가 — 소실 1건이면 반려)
   - 템플릿 사유 게이트 (블록마다 template_id 또는 custom_reason 필수)
   - 폰트 role 대조 게이트 (플랜의 폰트 선택 ↔ config/fonts.json roles)
   - side_tables/banners/aux 소비 게이트 (조건 필드 포함 전량 귀속)
3. **reviewer 기준 교정**: "중앙값 이탈" 가점 삭제, "기획 대비 검수"를 미감보다 앞에 배치.
   벤치마크 문구를 "디자이너 완성본과 구분 불가 = 기획을 조형으로 완성한 상태"로 재정의
4. **4단계 회귀 규율**: 조립·검수 중 내용 변경 필요 시 플랜 수정 → 게이트 재통과 → 재승인
   후에만 반영
