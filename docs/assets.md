# assets — 에셋 3계층 체계

> 2026-08-09 확정. v3 실측(슬롯 30개)과 compliance §5-1, gap-v3-vs-goodcase 분석에서 도출.

상세페이지의 모든 시각물은 **공급 경로가 서로 다른 3계층**으로 나뉜다.
플랜 단계에서 모든 이미지 슬롯에 계층을 붙이고, 계층별로 다른 파이프가 처리한다.

## T0 — 절차 생성 (procedural)

**코드가 그 자리에서 만든다. provider·에셋 폴더 불필요.**

| 종류 | 도구 | 검증 |
|---|---|---|
| 배경 텍스처 (크래프트지·한지결·그레인·낟알 스캐터) | `pipeline/gen_textures.py` → `upload_assets` → 레이어드 fill | v3 PASS 83점 |
| 절취선/지그재그 divider, 말풍선 꼬리 | Plugin API VECTOR path | 코퍼스 구스밀 시그니처 (11곳) |
| 도넛 %배지(면적-수치 비례), 막대/라인 차트, 타임라인 | Plugin API 도형 + 텍스트 | v3 47:226 등 |
| 궤도형 라벨 다이어그램, 필 배지, 아이콘(드로잉) | Plugin API | good case 대비 밀도 보강 대상 |

원칙: **T0로 만들 수 있는 것은 이미지 파일로 요구하지 않는다.** 인포그래픽을 이미지로 받으면 수정 불가능한 덩어리가 된다.

## T1 — AI 생성 가능 (generable)

**사실을 주장하지 않는 시각물.** 분위기·질감·일반 소재.

- 예: 배경 무드 사진, 일반 재료 플랫레이(특정 제품이 아닌), 김이 오르는 질감 컷, 추상 그래픽
- provider: **Higgsfield 주력**(사용자 확정 — 계정 승인 대기) / Gemini·FLUX 폴백 (`pipeline/gen_images.py`)
- **compliance 하드 게이트** (§5-1):
  1. 제품 실물로 오인될 수 있는 연출 금지
  2. 신선식품·유아식품·건기식 카테고리는 생성 자체 블록
  3. 1장이라도 쓰면 **AI 활용 고지 텍스트 필수** — 매핑 json에 플래그

## T2 — 주입 필수 (evidence)

**이미지 자체가 증거인 것. 생성하면 편의가 아니라 위조다.**

| 종류 | 왜 생성 불가인가 |
|---|---|
| 제품 실물컷·단면·패키지 | 소비자가 받을 물건의 표시 — 오인 유발 시 표시광고법 위반 |
| 인물(모델·셀럽) | 초상권·퍼블리시티권. 실존 인물 합성은 그 자체로 위법 소지 |
| 특허증·인증서·시험성적서 스캔 | 공문서 — 생성 = 위조 |
| 실제 구매 후기 캡처/원문 | 없는 후기 생성 = 기만적 광고 (대가성 표기 문제 이전의 문제) |
| 매장 외관·CCTV·생산 현장 | 실재 증명이 목적인 사진 |

산출: 플랜 단계에서 **에셋 요청 매니페스트**(`data/assets/<fileKey>-request.md`)를 뽑아 사람에게 전달한다. 도착 전에는 designed placeholder(F3 회피 규격)가 자리를 지킨다.

## 슬롯 규약

- Figma 슬롯 이름: `IMG_<설명>` — 설명에 실물 힌트(제품컷/실물/인물/단면 등)가 있으면 T2로 자동 분류 (`gen_images.py`의 힌트 매칭)
- 계층 판정이 애매하면 **T2로 올려잡는다** (보수 원칙)
- 인벤토리: `python3 pipeline/gen_images.py list <fileKey> <rootNodeId>` — v3 실측: 30슬롯 = T1 18 + T2 12 (T0는 슬롯이 아니라 fill/vector로 존재)

## 파이프라인에서의 흐름

```
플랜(plan.json) → 슬롯마다 tier 태깅
  T0 → 빌드 스크립트가 즉시 생성 (텍스처는 upload_assets 경유)
  T1 → provider 큐 (Higgsfield 승인 후) + AI 고지 플래그
  T2 → 요청 매니페스트 발행 → 사람 폴더 대기 → 도착 시 upload_assets(nodeId)로 치환
```

**페이지의 "진짜 마지막 라운드"는 T2 도착 시점이다** — placeholder가 실사로 바뀌면 스캐터·타일 반복·대비를 재검수한다 (v3 검수자 지적).
